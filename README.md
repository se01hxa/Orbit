# Orbit Browser 0.3.0-beta.7 · Windows 배포 베타

Chromium을 내장한 Electron 기반 Windows 브라우저입니다. 세로 탭, 스페이스, 분할 화면과 자동 PIP를 중심으로, 0.3에서는 탭 정리와 일상적인 브라우저 기능을 넓히고 브랜드·아이콘·유리 질감 UI를 새로 만들었습니다.

## 설치와 실행

일반 사용자는 `Orbit-Setup-0.3.0-beta.7-x64.exe`를 실행해 설치합니다. Node.js나 관리자 권한은 필요하지 않습니다. 설치 위치를 선택한 뒤 시작 메뉴에서 Orbit을 실행하세요. 기존 Orbit을 닫고 새 설치 파일을 실행하면 기본 프로필의 탭·스페이스·로그인 데이터·색상 설정을 이어서 사용합니다.

설치 화면의 **바탕화면 아이콘 만들기**는 기본으로 선택되어 있으며 필요 없으면 해제할 수 있습니다. 기존에 바탕화면 바로가기가 없었던 경우에도 수동 업그레이드 중 이 항목을 선택하면 새로 만듭니다. 시작 메뉴 바로가기는 바탕화면 선택 여부와 관계없이 계속 생성합니다.

이번 파일은 코드 서명이 없는 Windows x64 베타라 게시자 또는 SmartScreen 경고가 나타날 수 있습니다. 업데이트는 새 설치 파일을 직접 실행하는 방식입니다. 공개 다운로드 주소와 자동 업데이트 서버는 연결되어 있지 않습니다. 배포·서명·CI 설정은 [DISTRIBUTION.md](DISTRIBUTION.md)를 참고하세요.

소스에서 실행하려면 Node.js 22 이상이 필요합니다. `Start-Orbit.cmd`를 실행하거나 다음 명령을 사용합니다.

```powershell
npm ci
npm start
```

## 0.3에서 새로 사용할 수 있는 기능

- **Orbit 메뉴:** 왼쪽 위 로고에서 새 창·시크릿 창·가져오기·탭 관리·즐겨찾기·보관함·확장 프로그램·개발자 도구·인쇄·설정에 접근합니다. 메뉴 안에서 페이지 확대·축소도 조절합니다.
- **실제 사이트 아이콘:** 페이지가 제공한 파비콘을 탭·즐겨찾기에 표시합니다. Google·YouTube·네이버·GitHub 빠른 링크에도 실제 사이트 이미지가 사용됩니다. 아이콘을 불러올 수 없는 사이트에는 지구본을 표시합니다.
- **탭 폴더와 이동:** 폴더 생성·이름 변경·접기·삭제, 탭 드래그 정렬, 폴더로 드래그 이동을 지원합니다. 탭을 오른쪽 클릭하면 고정·음소거·주소 복사·폴더 및 스페이스 이동을 할 수 있습니다. 폴더만 삭제하면 안의 탭은 유지됩니다.
- **즐겨찾기:** 페이지의 별 버튼 또는 `Ctrl + D`로 추가·제거합니다. 즐겨찾기는 스페이스를 바꾸어도 왼쪽에서 사용할 수 있습니다.
- **닫은 탭 보관함:** 일반 창에서 닫은 웹 탭을 최대 100개까지 보관하고 선택해 복원합니다. `Ctrl + Shift + T`로 가장 최근 탭을 다시 엽니다. 메뉴의 일반 탭 보관은 현재 스페이스의 고정되지 않은 탭을 닫아 보관합니다.
- **북마크 가져오기:** 다른 브라우저에서 내보낸 북마크 HTML 또는 Chromium Bookmarks JSON을 선택합니다. 현재 스페이스에 폴더와 고정 탭으로 가져옵니다. 로그인·암호·쿠키를 가져오는 기능은 아닙니다.
- **새 창과 시크릿 창:** 일반 창을 추가하거나 임시 메모리 세션의 시크릿 창을 엽니다. 시크릿 창의 탭·쿠키는 일반 프로필에 저장하지 않고 창을 닫으면 정리합니다. 다운로드한 파일은 남습니다.
- **페이지 도구:** 페이지 내 찾기, 확대·축소·초기화, 시스템 인쇄, PDF 저장, 개발자 도구를 지원합니다.
- **확장 프로그램 관리:** 일반 창의 현재 스페이스에 압축 해제된 확장 폴더를 불러오고, 팝업 열기·제거를 할 수 있습니다. Electron이 지원하는 일부 Chrome 확장 API만 동작합니다. Chrome 웹 스토어 설치나 전체 확장 호환은 제공하지 않으며, 일반 확장은 앱 재시작 후 다시 불러옵니다. Discord Custom RPC는 아래의 Orbit 호환 연결로 재시작 후에도 유지합니다.
- **내 Orbit 카드:** 표시 이름·한 줄 소개·그래픽을 바꾸고 카드 이미지를 PNG로 저장하거나 클립보드에 복사합니다. 이 기기에 저장하는 프로필이며 온라인 계정이나 공유 링크를 만들지 않습니다.

## 디자인과 기존 기능

새 로고는 코랄·퍼리윙클·딥블루의 열린 O 리본입니다. Windows 앱 아이콘부터 탭의 작은 심볼까지 같은 원본 SVG를 사용합니다. 핀·닫기·검색·메뉴 등 UI 아이콘은 직접 그린 SVG로 통일하고 탭 버튼의 클릭 영역을 넓혔습니다.

스페이스별 사용자 색상 위에 은은한 유리 표면과 파스텔 조명을 더했습니다. 홈페이지 카드·주소 검색·대화상자·메뉴를 다듬고, 다운로드에는 실제 수신량 기반 원형 진행률과 완료 표시를 추가했습니다. 크기를 알 수 없는 다운로드는 임의의 퍼센트를 표시하지 않습니다. Windows의 애니메이션 줄이기 설정을 존중합니다.

다음 기능도 계속 사용할 수 있습니다.

- 세로 탭과 고정 탭, 스페이스 생성·전환·이름 변경·삭제. 스페이스마다 사이트 로그인과 쿠키를 분리합니다.
- 현재 스페이스의 탭 두 개를 나란히 여는 분할 화면. 각 화면을 클릭하면 그 화면의 주소와 탐색 버튼이 활성화됩니다.
- 빠른 주소·탭 검색, 사이트 이동과 Google 검색, 스페이스별 배경색 변경.
- 저장 위치 선택, 다운로드 진행률·취소·완료 애니메이션과 저장 폴더 표시. 다운로드 목록은 현재 실행 중에 유지됩니다.
- 유튜브 자동 PIP: 재생 중 다른 탭·스페이스·앱으로 이동하면 다른 앱 위에 작은 영상 창을 띄웁니다. 원래 탭으로 돌아와 창에 포커스를 주면 영상이 페이지로 복귀합니다. 설정에서 자동 동작을 끄거나 상단 PIP 버튼으로 지원 사이트의 영상을 직접 띄울 수 있습니다.
- 설치 버전의 Windows 기본 브라우저 후보 등록, 설정에서 Windows 기본 앱 설정 열기. 기존 기본 브라우저를 자동으로 바꾸지는 않습니다.
- 사이트가 제공한 종료 확인, 카메라·마이크·위치·알림·클립보드 읽기 권한 확인, 현재 스페이스의 쿠키·캐시 삭제.

PIP와 로그인·보호 영상은 사이트 정책에 따라 동작이 달라질 수 있습니다. 앱을 다시 실행하면 마지막으로 닫은 일반 창의 탭과 설정을 복원합니다. 여러 일반 창 전체를 한꺼번에 복원하지는 않으며, 각 웹페이지의 뒤로·앞으로 탐색 기록은 현재 실행 중에만 유지됩니다.

## Discord 활동 연결 · 0.3.0-beta.7

Discord Custom RPC Bridge의 수정된 `extension` 폴더 또는 그 상위 프로젝트 폴더를 **Orbit 메뉴 → 확장 프로그램 → 폴더에서 추가**에서 선택합니다. 일반 창에서 현재 스페이스의 연결 안내를 확인하고 추가하면 **Orbit 호환 연결 · RPC 앱 연결됨** 상태가 표시됩니다. 이 연결은 앱 재시작 후 복원됩니다. 다른 스페이스에서도 공유하려면 해당 스페이스에서 추가하고, 전송을 멈추려면 확장 목록에서 제거합니다.

RPC 앱과 Discord 데스크톱 앱을 실행해야 합니다. Orbit은 승인한 일반 스페이스의 현재 탭과 재생 중인 탭의 제목·주소·파비콘·미디어 정보를 이 PC의 `127.0.0.1:39231`로 전달합니다. 시크릿 창, 새 탭 화면, 입력창 내용과 AI 대화 내용은 이 연결로 전달하지 않습니다. 시크릿 창에 포커스가 있으면 일반 탭 전송도 잠시 멈춥니다. 다른 앱 위에서 음악을 재생할 때는 재생 중인 탭 정보를 이어서 보냅니다.

RPC 설정의 **Orbit 활동 로고**에는 해당 Discord 애플리케이션에 등록한 `orbit` 자산 이름 또는 공개 PNG 주소를 넣습니다. 일반 사이트는 사이트 로고를, 영상·음악은 썸네일·앨범 표지와 서비스 로고를 표시합니다. Orbit 로고는 사이트 정보가 없을 때만 대체 이미지로 사용합니다. 로컬 파일·로컬 서버·SVG 주소는 Discord 활동 이미지로 사용하지 않습니다.

## 비밀번호 관리자와 스페이스 아이콘 · 0.3.0-beta.7

상단 **열쇠 버튼**, **Orbit 메뉴 → 비밀번호 관리자**, **설정 → 비밀번호 관리자**에서 현재 스페이스의 저장된 계정을 검색·입력·삭제합니다. HTTPS 페이지에서 로그인 폼을 제출하면 저장 여부를 묻습니다. 자동 제안이 없는 사이트에서는 로그인 정보를 입력한 뒤 관리자의 **현재 페이지 로그인 저장**을 누릅니다. 저장 확인 없이 계정을 보관하지 않습니다.

같은 HTTPS origin(프로토콜·호스트·포트)에 계정이 하나 있으면 다음 방문의 빈 로그인 폼에 자동 입력합니다. 로그인 버튼은 직접 누릅니다. 계정이 여러 개면 관리자에서 선택해 **입력**합니다. 다른 사이트·스페이스·시크릿 창에는 입력하지 않습니다. HTTP, iframe 로그인 폼, 일부 다단계·맞춤형 로그인 화면은 자동 감지가 제한될 수 있습니다. 시크릿 창에서는 저장소를 사용하지 않습니다.

계정 전체는 `%APPDATA%/Orbit/orbit-passwords.bin`에 Windows DPAPI를 사용하는 Electron `safeStorage`로 암호화합니다. 암호화가 없으면 저장하지 않고, 복호화에 실패해도 기존 파일을 덮어쓰지 않습니다. 비밀번호 원문은 관리 화면·일반 앱 상태·클립보드·RPC로 내보내지 않습니다. Windows의 같은 사용자 권한으로 실행되는 다른 프로그램까지 격리하는 기능은 아닙니다. 마스터 암호, 암호 보기·내보내기, 패스키, 기존 Chrome 암호 자동 가져오기와 클라우드 동기화는 포함하지 않습니다.

새 프로필은 **시작의 궤도** 하나로 시작합니다. 새 스페이스 기본 이름은 **궤도 - 1**, **궤도 - 2**처럼 정하며 직접 입력한 이름도 그대로 사용합니다. 모든 스페이스는 해당 배경색을 반영한 Orbit 리본 로고를 사용하고, 추가 화면에서 이름·색상·로고를 미리 봅니다. 기존 기본 이름인 개인·업무는 시작의 궤도·궤도 - 1로 바꾸며 기존 스페이스 ID·탭·쿠키·저장 계정과 사용자가 정한 이름은 유지합니다.

## 로그인 팝업 호환성 · 0.3.0-beta.7

Google 로그인 등에 사용하는 빈 팝업을 먼저 열고 HTTPS 제공자 페이지로 이동하는 흐름을 지원합니다. 원래 탭과의 `window.opener`·메시지 전달·현재 스페이스의 세션을 유지하며, 원격 페이지의 샌드박스와 Node 차단은 유지합니다. 파일·데이터 주소의 팝업은 허용하지 않습니다. 로그인 제공자 자체의 브라우저 지원 정책과 계정 인증 제한은 별개입니다. 시험 계정 대신 로컬 로그인 모형으로 팝업 생성→제공자 이동→완료 메시지→닫기를 검증했습니다. 실제 Google 계정 인증 완료는 자동 검증하지 않았습니다.

## 주소창 자동완성과 기록 · 0.3.0-beta.7

주소창에서 열린 탭·즐겨찾기·현재 스페이스의 방문 사이트와 최근 검색어를 추천합니다. YouTube·Google·네이버·GitHub·Pinterest 바로가기도 입력 내용에 맞춰 제안합니다. 방향키와 Enter 또는 클릭으로 선택합니다. 검색·방문 기록은 이 기기에 최대 500개를 저장하며 앱 재시작 후에도 복원합니다. 방문 주소의 쿼리와 해시는 제거하고 로그인·인증 콜백 주소는 기록 대상에서 제외합니다.

**설정 → 검색과 자동완성**에서 **주소창 자동완성**, **검색·방문 기록 저장**, **Google 추천 검색어**를 각각 켜고 끕니다. Google 추천은 기본으로 꺼져 있습니다. 켜면 입력 중인 검색어를 Google에 전송하고, 잠깐 입력을 멈춘 뒤 추천을 가져옵니다. URL·이메일 형태 입력은 전송하지 않습니다. 오류가 나면 로컬 추천만 유지합니다. 자동완성을 끄면 주소창에서 추천 결과를 표시하지 않습니다.

**Orbit 메뉴 → 검색·방문 기록** 또는 설정의 **기록 보기·삭제**에서 개별 기록이나 현재 스페이스 기록 전체를 삭제합니다. 기록 저장을 꺼도 기존 기록은 남으므로 원하면 이 화면에서 삭제합니다. 열린 탭·닫은 탭 보관함 등 기존 복원 기능은 별도입니다. 시크릿 창에서는 검색·방문 기록을 저장하거나 일반 기록을 표시하지 않고 온라인 추천도 요청하지 않습니다.

## 단축키

- `Ctrl + L`: 주소·탭 검색
- `Ctrl + T` / `Ctrl + W`: 새 탭 / 현재 탭 닫기
- `Ctrl + N` / `Ctrl + Shift + N`: 새 창 / 새 시크릿 창
- `Ctrl + Shift + T`: 최근 닫은 탭 복원
- `Ctrl + D`: 즐겨찾기 추가·제거
- `Ctrl + Tab` / `Ctrl + Shift + Tab`: 탭 전환
- `Ctrl + F`: 페이지에서 찾기
- `Ctrl + +` / `Ctrl + -` / `Ctrl + 0`: 확대 / 축소 / 원래 크기
- `Ctrl + P` / `Ctrl + Shift + P`: 인쇄 / PDF 저장

- `Ctrl + \`: 분할 화면 켜기·끄기

- `F11`: 전체 화면
- `F12` / `Ctrl + Shift + I`: 개발자 도구

## 데이터와 지원 범위

사용자 데이터는 Windows의 `%APPDATA%/Orbit`에 저장합니다. 스페이스마다 별도 Chromium 세션을 사용하며, 스페이스를 삭제하면 그 스페이스의 탭과 사이트 저장소도 삭제합니다. 사이트 권한 결정은 현재 실행 중에 유지됩니다.

시크릿 창은 이 기기의 일반 프로필에 방문 탭과 쿠키를 남기지 않는 기능입니다. 방문 사이트나 네트워크 운영자에게 활동을 숨기지는 않습니다. 북마크 가져오기·즐겨찾기 변경·확장 추가는 일반 창에서 사용합니다.

이 앱은 Chromium 소스를 직접 수정한 포크가 아닌 Electron 기반 브라우저입니다. **Arc Max 등 AI 기능, Arc 계정, 클라우드 동기화, Chrome 웹 스토어 전체 호환, 자동 업데이트 서버는 제공하지 않습니다.** 메뉴의 업데이트 확인은 현재 버전과 수동 업데이트 방법을 안내하며 서버에서 최신 버전을 조회하지 않습니다. 외부 앱에서 전달되는 HTTP·HTTPS 주소는 지원하고 로컬 HTML 파일 연결은 등록하지 않습니다.

제거는 Windows의 설치된 앱 목록에서 진행합니다. 제거해도 브라우저 데이터와 다운로드한 파일은 보관합니다. 다시 설치하면 저장된 데이터를 사용할 수 있습니다.

```powershell
npm test

npm run test:oauth

node tests/features.cjs

```

모델·북마크 검증은 주소 처리, 저장 상태 복구와 북마크 파싱을 검사합니다. 실제 Electron 검증은 별도 프로필과 로컬 테스트 사이트로 탐색·세션 분리·PIP·다운로드·새 기능을 확인합니다. 설치 검증은 생성된 설치 파일의 설치·업그레이드·실행·제거와 데이터 보존을 확인합니다. 개발 검증은 일반 사용자가 실행할 필요가 없습니다.

배포 앱은 ASAR와 무결성 검증을 사용하고 Node 실행 모드·Node 검사기를 꺼 둡니다. 개발용 Electron 자동화의 성공만으로 설치 파일의 동작을 확인한 것으로 간주하지 않습니다. 모든 외부 사이트와 보호 콘텐츠의 호환성을 보장하는 검증은 아닙니다.

## Orbit 내부 페이지
주소창에서 orbit://password-manager/passwords/, orbit://settings, orbit://history, orbit://downloads, orbit://extensions, orbit://bookmarks, orbit://spaces, orbit://tabs, orbit://archives, orbit://version, orbit://help를 열 수 있습니다. 전체 지원 목록은 orbit://urls입니다. 같은 chrome://, arc:// 주소는 orbit://로 정규화합니다. 내부 페이지는 외부 웹사이트용 WebContents에 로드하지 않으며 저장된 탭도 복원됩니다. 지원하지 않는 Chromium 전용 페이지는 지원하지 않음을 표시합니다. Google 계정 동기화, Google 비밀번호 유출 점검, Chrome 플래그 전체를 구현한 버전은 아닙니다.
