# Orbit visual identity

An original open-ribbon **O**: warm coral, periwinkle, and deep blue. The open seam suggests a browser that keeps moving. All artwork is original vector geometry; it does not reproduce Arc's A symbol or wordmark.

- `../orbit.svg`: application tile with a soft ivory/lilac background.
- `orbit-mark.svg`: transparent symbol for chrome, cards, and small UI.
- `orbit-mark-mono.svg`: single-color alternative for high-contrast placement.
- `icon-16.png` through `icon-256.png`: Windows icon resolutions.
- `../orbit.ico`: multiresolution Windows application icon.
- `../icons.js`: original 24px UI icon family, no icon font or network dependency.

Use equal width and height. Keep clear space of at least one fifth of the symbol's width. Use the icon tile for Windows shortcuts; use the transparent mark inside the app.

The interface icons are original artwork distributed as part of Orbit. Site favicons belong to their respective owners and are loaded separately from actual website metadata.
