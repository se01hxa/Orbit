# Site icons

The Google, YouTube, NAVER and GitHub shortcut icons are each site's actual favicon, fetched from that site's published icon links. PNG copies are bundled for clear offline rendering. Original ICO files are retained where provided.

- Google: https://www.google.com/favicon.ico
- YouTube: icon URL published by https://www.youtube.com/
- NAVER: https://www.naver.com/favicon.ico
- GitHub: https://github.com/favicon.ico

These marks identify links to their respective services; they are not the Orbit application brand. Other website icons are obtained from that site's favicon metadata at runtime.
